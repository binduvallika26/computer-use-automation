# Evidence provenance

All account data is synthetic. Persisted events and results deliberately omit input values and extracted balances.

## Discovery

`discovery/c40babdbd7a04143b68bc8df5580fa3d/` was generated on 2026-09-09 by the actual discovery engine against live Chromium. The Codex assistant supplied six decisions through `--planner stdio`, reading a fresh observation after each action: fill member input, search, open member, open savings, read balance, finish. The application checked policy, acted on the real UI and emitted `capability.json` only after the final checkpoint succeeded.

Provider provenance is `external-stdio`. No application OpenAI API response ID exists for this run. This demonstrates a real external LLM operating the loop, but is not evidence of the separate OpenAI provider integration or a run paid through the submitter's own API credentials. That remains to be recorded using the README discovery command. Stdin also permits humans; its event label alone cannot attest that the writer was a model. This provenance statement identifies the actual writer for this particular run.

## Replay

`replay/` is generated by `python -m scripts.record_replays --artifact evidence/discovery/c40babdbd7a04143b68bc8df5580fa3d/capability.json` against fresh browser sessions. Every replay logs `provider: none`. Scenarios include another member, not found, slow load, known notice, permission denial and session expiry with simulated takeover.

The expired-session operator is a test driver executing UI actions in the same page while automation ownership is suspended. Its events are named `simulated_human_action`. A real person can exercise the same mechanism with `--manual-handoff`; no real-human completion is claimed here.

`failure-state.json` contains control match counts, visibility, enabled state and recognized error codes. These are richer structural observations, not raw screenshots or DOM dumps. `result.json` preserves the status/code/step and omits outputs. Balances are only returned to the process caller.
